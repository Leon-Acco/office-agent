# 欢迎使用 Agent 办公室

这是一家「AI 虚拟公司」:每位员工都是一名 AI,各自绑定代码仓库、知识与技能。你不需要知道该问谁,像走进真实公司一样提问即可。

## 第一步:在总前台提问

打开左侧「总前台」,直接用自然语言描述问题。系统会自动分诊到最对口的 AI 员工,并流式返回回答。

> 例:「V2X 消息编解码在哪个仓库实现的?」

## 第二步:找对口员工单聊

打开「员工办公室」,选择具体员工发起单聊,绕过分诊、直连专家。适合围绕同一领域的连续追问。

## 第三步:跨领域问题用协作会议室

打开「协作会议室」,提交一个需要多方协作的任务。多名员工会并行产出草案、互相评审,最后合成一份完整方案并落盘保存。

## 第四步:上传你的资料

打开「资源中心」,上传文档或接入代码仓库。上传后即可在对话中被检索引用;在「管理与治理 → 员工」里还能把资源绑定给指定员工,让他优先使用你的资料。

## 第五步:了解系统全景

- **公司总览**:组织 KPI 与员工状态仪表盘
- **关系图谱**:公司 → 部门 → 领域 → 员工的圈层视图
- **文档说明**:设计文档与产品方案(即文档中心)

## 小提示

- 回答底部可以点赞 / 点踩,反馈会进入公司 KPI
- 对话结论可以沉淀为知识,审核通过后全员可检索
- 遇到异常行为,可查看「管理与治理」中的审计日志
